# 交给 Codex 的首版开发任务

下面的任务可直接用于本仓库的新开发会话。

---

请在当前 lead-mind 仓库实现小红书旅游内容获客首版。

先读取 `README.md` 和 `docs/requirements/v0.1-xiaohongshu.md`，以需求文档作为验收基线。检查当前仓库与适用的 AGENTS.md，保留已有用户修改。先记录实施计划，然后分阶段实现并验证，不停留在静态界面或演示数据。

默认采用 React + TypeScript + Vite 前端、FastAPI 后端、SQLite 持久化和本地图片存储。核对所用依赖的官方文档并锁定版本。按本机单用户应用交付，真实账号、模型和平台连接器通过服务端配置接入。

按以下顺序完成：

1. 工程、数据库迁移、配置、账号、线路与素材库。
2. 原始需求、选题、图文草稿的手工流程与保存。
3. AI 结构化生成、原文证据和人工修改保护。
4. 审核、版本失效、发布提醒、人工回填和发布幂等控制。
5. 咨询提取、线索查重、分配接收、有效性反馈与来源归因。
6. 养号每日任务、今日工作台和真实指标。
7. 核验可用的小红书服务，实现实际适配器并记录能力；开发时的工具不等于独立应用运行时依赖。
8. 执行需求验收清单中的关键业务测试和完整本地端到端流程。

缺少模型密钥、平台登录或接口能力时，继续完成可独立实现的功能。明确保留待配置/未验证状态，演示模式必须隔离并标记，不能以假数据宣称真实接入成功。发布真实笔记、评论或私信前，需要用户对具体内容和账号明确确认；自动化测试仅使用模拟连接器。

最终报告包括：已实现模块、启动命令、实际测试结果、真实平台验证结果、未完成项及其原因。不要承诺尚未验证的获客效果。
